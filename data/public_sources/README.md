# Public Data Sources

The paper-scale workflow uses public PV and price sources in addition to the confidential demand profile.

- PV profiles: generated from PVGIS historical weather data.
- Electricity prices: Italian PUN hourly market-price records, processed to EUR/kWh.

The public repository does not bundle processed full-year PVGIS or PUN files, because source attribution and any redistribution terms should be checked before release. Expected paper-scale file names are listed in `DATA_AVAILABILITY.md`.
